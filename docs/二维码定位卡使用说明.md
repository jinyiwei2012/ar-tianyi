# 二维码定位卡使用说明

本定位卡用于把“AR 世界/平面检测问题”和“Live2D 模型放置问题”拆开验证。应用不解析二维码内容，而是用 AR Foundation 的图像跟踪识别整张定位卡，并使用已知的 `120 mm × 120 mm` 物理尺寸恢复空间位姿。

## 文件

- 打印文件：`../output/pdf/LuoTianyiDeskMarkerV1-A4-120mm.pdf`
- Unity 参考图：`../LuoTianyiAR/Assets/AR/Markers/LuoTianyiDeskMarkerV1.png`
- 二维码内容：`LuoTianyiAR|marker=desk-v1|size_mm=120`
- Unity Reference Image 名称：`LuoTianyiDeskMarkerV1`

## 打印和摆放

1. 打印 PDF 时选择“实际大小”或 `100%`，不要选择“适合页面”。
2. 用尺测量黑色外框所围成的正方形，必须为 `120 mm × 120 mm`。
3. 将纸张固定到平整、哑光、不会弯曲的表面；不要覆亮膜。
4. 把定位卡平放在桌面，TOP 箭头正面朝上且完整可见。
5. 建议手机与卡片保持约 `0.3–1.2 m` 距离，缓慢改变角度扫描。

## 应用内显示

识别成功后，卡片上会显示：

- 红色：定位卡局部 `+X`，指向图片右侧。
- 绿色：定位卡局部 `+Y`，即图像表面法向。
- 蓝色：定位卡局部 `+Z`，指向 TOP 箭头。
- 白色：Unity 按 `120 mm` 绘制的卡片外框，应与打印外框重合。

顶部状态会显示二维码位姿与 AR 水平面的对比：

- 高度误差：平面命中点沿定位卡法向的距离。
- 法向误差：平面法向与定位卡法向的夹角。
- 平面内偏移：命中点与定位卡中心在卡片平面内的距离，仅用于检查 Raycast 对应关系。

当前通过阈值为高度误差不超过 `3 cm`、法向误差不超过 `5°`。

## 如何判断问题位置

1. 坐标轴和白框能长时间贴住纸面，但“二维码与水平面不一致”：优先检查 AR 平面检测或 Raycast 选面。
2. 坐标轴和白框稳定，平面对比通过，但 Live2D 模型偏移或飘动：优先检查模型父节点、Anchor、脚底校正和坐标空间转换。
3. 位置稳定但角色没有正对相机：检查 `CylindricalBillboard`，与平面定位无关。
4. 坐标轴自身相对纸面明显漂动：图像跟踪或 AR 会话定位不稳定，先改善照明、卡片平整度和可见面积。

打开右上角“调试”，复制诊断报告。报告中的 `--- 二维码定位 ---` 会包含追踪状态、定位卡 Pose、相对首次识别的变化以及平面对比误差。

## 重新生成定位卡

定位卡源由脚本生成，修改二维码或图案后必须重新运行场景配置并重新构建 APK：

```powershell
python -m pip install -r tools/requirements-marker.txt
python tools/generate_qr_marker.py
```

不要在不更新 Unity Reference Image Library 的情况下修改或裁剪 PNG，也不要改变打印尺寸后继续使用 `0.12 m` 的参考宽度。
